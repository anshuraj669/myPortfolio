Tracebase

Self-hosted AI for code, logs and backups

A private, self-hosted assistant that runs on a NAS or any Docker host. It indexes every repository for semantic code search and Q&A with file:line citations, and can copy a feature from an old project into a new one — adapting names, imports and dependencies and showing the diff first. Its Log Detective groups production errors, maps stack traces to the failing line, finds the commit that introduced it with git blame and suggests a fix. Secrets and personal data are redacted before storage; team mode adds per-repo access tokens and an audit log. Exposed to Claude Code and other agents over MCP.
